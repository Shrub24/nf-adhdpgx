ADHD PGX:
An end to end bioinformatics nf-core pipeline to process and report genetic interactions with ADHD medications for human genomes.

Doing alignment to variant calling workflow - similar to standard GTK4.

However, this is a specific tailored task that is designed specifically for SOTA ADHD genetic indicators, so we deviate from standard pipelines to provide reporting as well as SV calling for relevant variants such as CYDP26 (perhaps using cyrius or similar?)
